Le plus difficile n’est pas d’entretenir des crevettes, c’est de **démarrer dans le bon ordre**. Voici l’essentiel ; le détail est dans le [guide pour débuter](/debuter-aquarium-crevettes/).

## Les six étapes

1. **Choisir l’espèce** : [quelle crevette pour débuter](/quelle-crevette-pour-debuter/).
2. **Choisir le bac** : [quel aquarium pour crevettes](/quel-aquarium-pour-crevettes/).
3. **Installer** : [installer l’aquarium](/installer-aquarium-crevettes/).
4. **Cycler** : [cycler un aquarium](/cycler-aquarium-crevettes/).
5. **Acclimater** : [acclimatation](/acclimatation-crevettes/).
6. **Observer** : nourriture modérée, [mesures régulières](/mesurer-parametres-eau-crevettes/).

## Ce qu’il faut éviter

Introduire des crevettes dans un bac neuf, changer l’eau en grande quantité, ajouter des produits sans mesurer, suralimenter. La liste complète : [erreurs de débutant](/erreurs-debutant-crevettes/).

## FAQ

### Combien coûte un premier aquarium à crevettes ?
Cela dépend du matériel choisi. Le budget principal est le bac, le filtre et les tests ; les crevettes elles-mêmes sont généralement la partie la moins chère.

### Combien de temps avant de voir des bébés ?
Souvent plusieurs semaines à quelques mois après l’introduction, si le bac est stable.
